### Задание 1 **(3)**
*Рассмотрим следующую программу на С++.*
```
#include <iostream>
#include <cmath>
int main() {
   double x = 0;
   const auto Pi = std::acos(0) * 2;
   std::cout << Pi << std::endl;
   return 0;
}
```
*Проверьте четыре способа объявления* **Pi**.
* ```const auto Pi = acos(0) * 2;```
* ```constexpr auto Pi = std::acos(0) * 2;```
* ```const auto Pi = acos(x) * 2;```
* ```constexpr auto Pi = std::acos(x) * 2;```

*Что можно сказать об этих вариантах? Проверьте, в каких вариантах объявляется константа этапа трасляции.*

*Тексты программ разместите в папке с номером задания*

**Ответ:** 
1. const auto Pi = acos(0) * 2; - не является константой этапа трансляции, компилируется без ошибок.
2. constexpr auto Pi = std::acos(0) * 2; - является константой этапа трансляции, но не компилируется т.к обязательным условием констант времени компиляции является то, что значение должно быть известно перед компиляцией, а **std::acos(0) * 2** считается во время выполнения программы.
3. const auto Pi = acos(x) * 2; - не является константой этапа трансляции, значение константы можно изменить за счёт изменения переменной x, компилируется без ошибок
4. constexpr auto Pi = std::acos(x) * 2 - является константой этапа трансляции, но так же не компилируется потому что выражение **std::acos(x) * 2** выполняется при компиляции

### Задание 3 **(2)**
*Проверьте работу следующего фрагмента программы на С++.*
```
int s = 0;
for (int i = 0; i < 4; i++) {
   for (int i = 0; i < 3; i++) {
      s += i;
   } 
   s += i; 
}
std::cout << s;
```
*В результате каких вычислений был получен ответ? Дайте подробный ответ.*

**Ответ:**
**1. Внутренний цикл for**
   s = 0 + 1 + 2 = 3. Внешний цикл прогоняется 4 раза, поэтому s = 3 * 4 = 12
**2. Внешний цикл for**
   После выполнения каждого внутреннего цикла к s прибавляется i внешнего цикла, итого s = 12 + 0 + 1 + 2 + 3 = 18

### Задание 6 **(2)**

*Рассмотрим следующий фрагмент программы. Эта программа 1000000 раз обменивает значения двух длинных 
строк с использованием третьей строки. Проверьте, насколько быстро она работает.*

```
std::string a(100000, 'a');
std::string b(100000, 'b');
for (int i=0;i<1000000;i++) {
   std::string c(a);
   a = b;
   b = c;
}
std::cout << a[0] << b[0];
```
*Попробуйте использовать для обмена значений строк функцию* **swap**. 
*Проверьте, изменилось ли время работы. В чем ошибка исходной программы?
Исправьте исходную программу, чтобы ускорить ее работу. Изменения не должны 
затрагивать общий вид программы (присваивания, использование временной переменной).*

**Ответ:**
```
#include <iostream>
#include <string>

int main() {
    std::string a(100000, 'a');
    std::string b(100000, 'b');

    for (int i = 0; i < 1000000; i++) {
        std::swap(a, b);
    }

    std::cout << a[0] << b[0];
}
```
